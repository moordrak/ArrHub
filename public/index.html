Address of the Docker host. Recommended: a docker-socket-proxy on that host (http://host:2375). Also https://host:2376 with TLS certificates, or unix:///var/run/docker.sock if ArrHub runs on the same host.
E.g. Portainer or Dockge, opened from the Docker card.
Host name or IP of the Docker host used for the container web pages. Empty = the host from the Docker address.
Nginx Proxy Manager – https addresses (optional) ArrHub reads your proxy hosts and opens each container at its https domain instead of http://IP:port – no browser warning about http inside https. Arr services also use the addresses from their cards above.

Network

ArrHub then talks only to your services: no update check on GitHub and no images from TMDB/TVDB. Posters and backgrounds come only from Radarr and Sonarr (MediaCover), request posters from Seerr's image cache. Items without a local image show a placeholder.

SSL / TLS – own CA certificate

Paste the certificate of your own certificate authority (the public .crt / .pem, not the private key). ArrHub then fully verifies your https:// services against it. Several certificates (a chain) can be pasted one after another.
